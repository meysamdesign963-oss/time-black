# تایم بلک | Time Black

پلتفرم اجتماعی مدیریت زمان و رقابتی — یک پلتفرم وب کاملاً فارسی برای ثبت زمان‌های مطالعه، رقابت با دیگران، ایجاد محتوا و برداشت جوایز ماهانه.

---

## ویژگی‌های کلیدی

### تایمر و مدیریت زمان
- تایمر هوشمند با پشتیبانی از تکنیک پومودورو (Focus / Break)
- مدیریت وظایف با دسته‌بندی، اولویت، تگ و زمان‌بندی تکراری
- آمار تفکیکی از زمان هر کاربر بر اساس تاریخ شمسی و قمری

### رقابت و لدربورد
- لدربورد رتبه‌بندی کاربران بر اساس زمان ثبت‌شده
- جوایز ماهانه و هفتگی (جامعه / تخصصی)
- نمایش بدی و برنزه‌های کسب‌شده
- دوره‌های مسابقه قابل تنظیم توسط مدیر

### شبکه اجتماعی
- انتشار پست با پشتیبانی از تصویر و ویدیو
- ریپوست و نقل‌قول از پست‌ها
- سیستم لایک و کمنت با پشتیبانی از پاسخ تودرتو
- دنبال‌کردن (Follow) کاربران
- پیام‌رسانی خصوصی (DM)

### پنل مدیریت
- داشبورد مدیریت با آمار کلی پلتفرم
- مدیریت کاربران (بلاک، محدودیت، تغییر نقش)
- مدیریت محتوا و فایل‌ها
- سیستم گزارش و نظارت
- اعلان‌های سایت
- تخصیص جوایز به کاربران

### احراز هویت
- ثبت‌نام با رمز عبور یا OTP (ارسال کد به شماره موبایل)
- پروفایل کاربری با آمار زمان عمومی
- پشتیبانی از حالت تاریک (Dark/Light)
- راسپنسیو برای موبایل

## نصب و راه‌اندازی

### 1. کلون کردن پروژه

```bash
git clone <repository-url>
cd time-black
```

### 2. نصب وابستگی‌ها

```bash
bun install
```

### 3. تنظیم متغیرهای محیطی

فایل `.env` را مستقیم ویرایش کنید یا از فایل نمونه استفاده کنید:

```bash
cp .env.example .env
```

متغیرهای حاضر:

| متغیر | توضیحات |
|---|---|
| `DATABASE_URL` | آدرس فایل دیتابیس SQLite |
| `JWT_SECRET` | کلید رمزنگاری JWT |
| `JWT_REFRESH_SECRET` | کلید رمزنگاری Refresh Token |

### 4. تنظیم دیتابیس

```bash
# ایجاد جدول‌ها در دیتابیس
bun run db:push

# تولید Prisma Client
bun run db:generate

# (اختیاری) اجرای seed برای داده‌های نمونه
bunx prisma db seed
```

### 5. راه‌اندازی توسعه

```bash
bun run dev
```

سپس بروزر را در آدرس `http://localhost:3000` ببینید.

## مدل‌های دیتابیس

| مدل | توضیح |
|---|---|
| `User` | کاربران با نقش‌های BOSS / ADMIN / USER |
| `Task` | وظایف با دسته‌بندی و اولویت |
| `TimeEntry` | جلسات ثبت زمان (Focus / Break / Pomodoro) |
| `Post` | پست‌ها با پشتیبانی از ریپوست |
| `PostLike` / `CommentLike` | لایک پست و کمنت |
| `Comment` | کمنت‌ها با پشتیبانی از پاسخ تودرتو |
| `Follow` | رابطه دنبال‌کننده / دنبال‌شونده |
| `Message` | پیام‌های خصوصی |
| `Notification` | اعلان‌های کاربر |
| `OtpCode` | کدهای OTP برای ورود با شماره موبایل |
| `Session` | جلسات کاربری برای کنترل همزمان |
| `Report` | گزارشات کاربران |
| `UserAward` | جوایز و برنزه‌ها |
| `Announcement` | اعلان‌های سایت |
| `CompetitionPeriod` | دوره‌های مسابقه |
| `AuditLog` | لاگ اقدامات حساس |
| `SiteSetting` | تنظیمات سایت |

## اسکریپت‌های مفید

```bash
bun run dev          # راه‌اندازی توسعه
bun run build        # بیلد تولید
bun run start        # راه‌اندازی تولید
bun run db:push      # ایجاد/بروزرسانی جدول‌ها
bun run db:migrate   # میگریشن دیتابیس
bun run db:generate  # تولید Prisma Client
bun run db:reset     # بازنشانی کامل دیتابیس
bun run lint         # اینسپکشن کد
```
